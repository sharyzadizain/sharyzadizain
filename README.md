## About

I work on interfaces, prototypes and visual systems for digital products, and I take them all the way: research → concept → design system → interactive prototype in real code. The mockup is not the end of my job; the working screen is.

Current focus: product environments and AI-native tools that genuinely help the people using them. Interested in AI, VR and motion design; I take part in hackathons and build my own products.
