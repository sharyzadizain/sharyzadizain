## How I work

**Research → concept → design system → prototype in real code.** The mockup is not the end of the
job; the working screen is. I care about pixels, motion and the systems behind them, and I keep
the process documented so the product runs without me.

| | |
|---|---|
| **Product** | product design · UX research · user scenarios · product analytics |
| **Interface** | UI/UX · design systems · motion · prototyping |
| **Code** | TypeScript · Lit · Vite · SwiftUI · Tauri · Docker · AI coding with Claude and Codex |
| **Tools** | Figma · FigJam · Photoshop · After Effects · GitHub |
| **Soft skills** | systems thinking · attention to detail · quick adaptation · independence · teamwork · communication |
